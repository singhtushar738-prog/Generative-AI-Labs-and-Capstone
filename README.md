# Generative AI Labs and Capstone Project

## Overview
This repository contains four laboratory experiments and one capstone project completed as part of the Generative AI coursework. The implementations use Python and Google Colab along with popular deep learning and generative AI libraries.

## Laboratory Experiments

### Lab 1 – Variational Autoencoder (VAE)
- Dataset: MNIST
- Objective: Generate handwritten digit images using a Variational Autoencoder.
- Technology: Python, PyTorch

### Lab 2 – Generative Adversarial Network (GAN)
- Dataset: Fashion-MNIST
- Objective: Generate synthetic fashion images using a GAN.
- Technology: Python, PyTorch

### Lab 3 – GPT-2 Text Generation
- Model: GPT-2
- Objective: Generate text using a pretrained language model.
- Technology: Python, Hugging Face Transformers

### Lab 4 – Stable Diffusion
- Model: Stable Diffusion
- Objective: Generate images from text prompts.
- Technology: Python, Hugging Face Diffusers

## Capstone Project – AI Study Tip Generator
An interactive AI-powered application that generates study guidance, revision tips, and practice questions based on user prompts.

**Technology:** Python, GPT-2, Hugging Face Transformers, Gradio.

## Execution
Each experiment is provided as a Jupyter Notebook (`.ipynb`). Open the notebook in Google Colab to view the code and execute the experiment.

## Note
Some experiments require downloading pretrained models or datasets and may require a GPU runtime. Actual results depend on successful execution and the available runtime resources.
